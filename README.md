# liftcode

Lift color code values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/liftcode/

## Install / run

```bash
git clone https://github.com/theworker02/liftcode.git
cd liftcode
node src/cli.js
node --test
```
